Design a modern, elegant, responsive Family Tree application called "Roots & Relations".

The application should allow users to build, visualize, manage, and explore their family genealogy in an intuitive way.

CORE CONCEPT:
Create an interactive family tree where each person is represented by a profile card connected to their parents, spouse/partner, children, and siblings. The tree should be visually clear even when the family becomes large.

DESIGN STYLE:
- Modern, premium, clean interface
- Warm family-oriented feeling
- Professional but friendly
- Minimal visual clutter
- Rounded cards and subtle shadows
- Soft neutral background
- Use elegant typography
- Use a calm natural color palette
- Clear hierarchy and spacing
- Responsive design for desktop, tablet, and mobile
- Support both light and dark mode

MAIN NAVIGATION:
Create a sidebar navigation containing:
1. Dashboard
2. My Family Tree
3. Family Members
4. Timeline
5. Photos & Memories
6. Events
7. Documents
8. Family Stories
9. Messages
10. Settings

DASHBOARD:
Create a dashboard showing:
- Family tree preview
- Total family members
- Number of generations
- Upcoming birthdays
- Upcoming anniversaries
- Recently added family members
- Recent family memories
- Recent activity
- "Add Family Member" primary button
- "Explore Family Tree" button

FAMILY TREE PAGE:
Create the main interactive genealogy visualization.

Features:
- Zoom in/out
- Pan around the tree
- Center tree
- Search family members
- Filter by generation
- Expand/collapse branches
- Switch between tree layouts
- Show relationships
- Highlight direct descendants
- Highlight ancestors
- Show spouses/partners
- Show siblings
- Display relationship labels

Each person should have a beautiful profile card containing:
- Profile photo/avatar
- Full name
- Birth year
- Death year if applicable
- Gender
- Small relationship indicator
- Expand button

Clicking a person opens a detailed profile panel.

ONBOARDING:
Create a beautiful onboarding flow:

Screen 1:
"Preserve your family story."

Screen 2:
"Build your family tree."

Screen 3:
"Connect generations."

Screen 4:
"Keep memories alive."

Then ask:
"What would you like to do first?"

Options:
- Build my family tree
- Import an existing tree
- Explore a family tree

FIRST-TIME TREE CREATION:
Start with the current user.

Ask:
"What is your name?"
Then:
"Who are your parents?"
"Do you have siblings?"
"Are you married or partnered?"
"Do you have children?"

Automatically generate the initial tree from these relationships.

VISUAL FAMILY TREE:
The tree should feel like the central feature of the application.

Use clear connecting lines between:
Parent → Child
Spouse ↔ Spouse
Sibling ↔ Sibling

Use different visual grouping for each generation.

Avoid overlapping cards and confusing connections.

Create a polished, production-ready interface rather than a simple wireframe.
